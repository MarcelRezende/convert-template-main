# 💱 Conversor de Moedas

Um conversor de moedas desenvolvido com **HTML, CSS e JavaScript**, criado para praticar conceitos fundamentais de JavaScript e manipulação do DOM.

<img width="914" height="851" alt="image" src="https://github.com/user-attachments/assets/832ea29c-3ea7-4b08-8a67-16366dbabea2" />



Link do projeto: https://marcelrezende.github.io/convert-template-main/

## 🚀 Funcionalidades

- 💰 Conversão de valores entre diferentes moedas
- 🇺🇸 Dólar (USD)
- 🇪🇺 Euro (EUR)
- 🇬🇧 Libra Esterlina (GBP)
- 🔢 Entrada de valores pelo usuário
- 🔄 Seleção da moeda desejada
- ⚡ Resultado da conversão exibido diretamente na página
- 📱 Interface adaptada para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📚 Conceitos praticados

Durante o desenvolvimento, foram praticados conceitos importantes de JavaScript, como:

- `const`
- `querySelector()`
- `getElementById()`
- `.value`
- `addEventListener()`
- `function`
- `if`
- `else`
- Operadores matemáticos
- Template literals
- Manipulação do DOM
- Eventos de formulário
- Conversão e tratamento de valores

## 💡 Como funciona

O usuário informa um valor, seleciona a moeda desejada e o JavaScript realiza o cálculo utilizando as cotações definidas no projeto.
